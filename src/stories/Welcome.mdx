A modern, headless, compound-component carousel library built on **Embla Carousel** and **Tailwind CSS v4** for React-based projects.

---

## Installation

```bash
npm install eglador-ui-react-carousel
```

## Setup

Add the following to your global stylesheet (e.g. `app/globals.css`):

```css
@import "tailwindcss";
@source "../node_modules/eglador-ui-react-carousel";
```

## Quick Start

```tsx
import {
  Carousel,
  CarouselContent,
  CarouselItem,
  CarouselPrevious,
  CarouselNext,
  CarouselPagination,
} from "eglador-ui-react-carousel";
```

## Features

- **Compound API** — `Carousel`, `CarouselContent`, `CarouselItem`, `CarouselPrevious/Next`, `CarouselPagination` (composition over configuration)
- **TypeScript-first** — full type safety on Embla options and plugins
- **Position system** — 16 pagination positions, 16 navigation positions (overlay + outside variants)
- **Pagination types** — `dots`, `fraction`, `numbers`, `dynamic`, `scrollbar`
- **Autoplay progress** — circular SVG countdown indicator
- **AutoHeight** — viewport adjusts to active slide
- **Parallax + Opacity** — Embla's official tween algorithm built-in
- **Plugin support** — pass any Embla plugin (`Autoplay`, `Fade`, `AutoScroll`, etc.)
- **`useCarousel` hook** — build fully custom controls
- **RTL & vertical** — first-class support
