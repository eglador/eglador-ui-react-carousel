# Installation

Package installation, peer dependencies, and Tailwind v4 integration.

---

## 1. Install the package

```bash
npm install eglador-ui-react-carousel
```

```bash
yarn add eglador-ui-react-carousel
```

```bash
pnpm add eglador-ui-react-carousel
```

## 3. Add `@source` for Tailwind v4

Tailwind needs to scan classes inside the package. Add the `@source` directive to your global stylesheet:

```css
@import "tailwindcss";

@source "../node_modules/eglador-ui-react-carousel";
```

The `@source` path varies based on your CSS file location:

## 4. Optional Embla plugins

Embla plugins (Autoplay, Fade, AutoScroll, etc.) are bundled with the package by default. If you want explicit control over versions, install them directly:

```bash
npm install embla-carousel-autoplay embla-carousel-fade embla-carousel-auto-scroll embla-carousel-auto-height
```

Use them via the `plugins` prop:

```tsx
import Autoplay from "embla-carousel-autoplay";
import Fade from "embla-carousel-fade";

<Carousel plugins={[Autoplay({ delay: 4000 }), Fade()]}>
  ...
</Carousel>
```
